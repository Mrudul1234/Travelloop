# Team Contributions — TRAVELOOP

This project was built with a collaborative effort focusing on both high-end aesthetic design and robust functional engineering.

## 👥 Core Team

Member 1 and Member 2 contributed for the UI of this website.

### **Member 1: UI & Frontend Development**
*   **Frontend Work**: Built the entire user interface and component library using Next.js 14 and Tailwind CSS.
*   **UI Design**: Conceptualized the "Modern Indian Aesthetic" (Glassmorphism + Traditional Motifs) and implemented responsive layouts.
*   **Interactivity**: Integrated interactive maps and dynamic trip planning features.

### **Member 2: System Architecture & Backend**
*   **Backend Work**: Designed the Supabase database schema, integrated APIs, and handled server-side logic.
*   **Architecture**: Managed the data flow between the AI engine (Gemini) and the database.
*   **Data Science**: Cleaned and integrated the Kaggle Indian Tourism dataset to provide 500+ authentic destinations.
*   **Security**: Implemented Row-Level Security (RLS) policies to protect user data.
